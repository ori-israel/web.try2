## משימות פתוחות

### 🔴 דחוף
- **תיקון prompt הצ'אט AI** — כשמשתמש שואל "כמה קלוריות אכלתי היום", ה-AI מנחש במקום לחשב נכון מהמנות האמיתיות. צריך לבדוק את system prompt ב-ai.js ולוודא שהוא קורא נכון את מנות החלבון/פחמימות/שומן ומחשב קלוריות לפי ערכי המנות האמיתיים (חלבון=27.5g=110 קק"ל, פחמימות=37.5g=150 קק"ל, שומן=12.5g=112.5 קק"ל).

### 🏋️ תרגילים
- **עדכון שמות תרגילים** לפי המינוח שנלמד בקורס מדריכי כושר (מיפוי שם ישן → שם חדש, טרם סופק)
- **הרחבת מאגר התרגילים** — תרגילים נוספים

### 🍎 תזונה — שינויים בהשראת Cronometer (בעקבות מחקר והשוואה)
מוסכם עד כה:
- **מעבר ממערכת "מנות" לגרמים חופשיים** — כרגע האפליקציה עובדת עם מנות קבועות מראש (חלבון/פחמימות/שומן), רוצים לעבור להזנה בגרמים כמו ב-Cronometer
- **סריקת ברקוד** למוצרים ארוזים — פיצ'ר חדש
- **שמירת מתכונים** (recipes) — משתמש בונה מתכון פעם אחת ואז מוסיף אותו כפריט שלם ביומן המזון
- **לחקור: מאגר מזון קהילתי** — אפשרות לחפש/לבחור מאכלים שמשתמשים אחרים הוסיפו למערכת (בדומה ל-Cronometer), עדיין בבדיקה

לא רלוונטי לחזון (הוחלט לא לעשות):
- מעקב מיקרו-נוטריאנטים (84 חומרים כמו ב-Cronometer) — יותר מדי רחב/מורכב, לא פארטו
- סנכרון עם שעונים חכמים (Apple Health / Garmin / Fitbit וכו')
- קהל היעד של Cronometer (ביוהאקרים/דיאטנים) אינו קהל היעד שלנו (מתחילים)
